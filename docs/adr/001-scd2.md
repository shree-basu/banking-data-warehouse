# ADR 001: Atomic SCD Type 2 dimensions

Status: accepted.

Customer, account, and merchant attributes need point-in-time analysis, so each is SCD2. A multi-statement BigQuery transaction materializes changed source rows, expires exactly one current row, inserts the replacement, asserts invariants, and commits. Durable surrogate keys are hashes of natural key and effective timestamp. Plain append-only INSERT was rejected because retries create duplicate current versions.
