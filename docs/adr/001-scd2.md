# ADR 001: Atomic SCD Type 2 dimensions

Status: accepted.

Customer, account, and merchant attributes need point-in-time analysis, so each is SCD2. A multi-statement BigQuery transaction materializes changed source rows, expires the current row, inserts the replacement, and commits atomically. Durable surrogate keys are hashes of natural key and effective date. The post-publication curated DQ gate asserts one current row and non-overlapping intervals before analytics refresh and batch success. Plain append-only INSERT was rejected because retries create duplicate current versions.

The accepted operating contract is chronological publication and oldest-first backfill. The procedures do not claim to recalculate neighboring validity intervals for arbitrary out-of-order historical dimension versions.
